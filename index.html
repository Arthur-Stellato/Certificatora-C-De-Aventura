Aula 1 · Criação do Personagem Variáveis, constantes, tipos, entrada, saída e expressões
Teoria

Pré-requisitos: Nenhum. É o começo da jornada.

Uma variável é um espaço na memória com nome e tipo. int guarda inteiros, float guarda decimais, char guarda um caractere, e um vetor de char guarda texto. Uma constante, marcada com const, não muda depois de criada.

printf mostra informações na tela e scanf lê o que a pessoa digita. Com +, -, *, / e % fazemos contas. Entre dois inteiros, a divisão descarta a parte decimal.

No jogo: O herói precisa de nome, vida, força e mana. O %49s limita o nome a 49 caracteres, sem espaços, para não ultrapassar a memória reservada.

const int VIDA_MAX = 70;
char nome[50];
int forca, mana;

scanf("%49s", nome);
scanf("%d", &forca);
scanf("%d", &mana);

int poderTotal = forca + mana;
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Crie o atributo agilidade, leia o valor com scanf e some no poder total.

Dica do exercício 1

Declare um int, use & no scanf e inclua a variável na soma.

Solução do exercício 1

Troque a linha do poderTotal por:

int agilidade;
printf("Digite a agilidade do personagem:");
scanf("%d", &agilidade);

int poderTotal = forca + mana + agilidade;

2. Mostre a média entre força e mana com duas casas decimais.

Dica do exercício 2

Entre dois inteiros a divisão descarta a parte decimal. Divida por 2.0 e imprima com %.2f.

Solução do exercício 2

Depois da linha do poderTotal:

float media = (forca + mana) / 2.0;
printf("Média: %.2f\n", media);
Aula 2 · Teste de Sorte Expressões relacionais e lógicas
Teoria

Pré-requisitos: Módulo 1.

Uma expressão relacional compara dois valores e resulta em verdadeiro (1) ou falso (0). Os operadores são >, <, >=, <=, == (igual) e != (diferente). Atenção: = atribui um valor, == compara.

Os operadores lógicos juntam condições: && (e), || (ou) e ! (não).

No jogo: Um Goblin aparece. Comparamos o poder do herói com o dele para saber quem é mais forte. O jogo não sorteia números: o resultado depende dos valores digitados.

if (poderTotal > poderInimigo) {
    printf("O herói é mais forte!\n");
} else if (poderTotal < poderInimigo) {
    printf("O inimigo é mais forte!\n");
} else {
    printf("Os dois têm o mesmo poder.\n");
}
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Mostre “O herói domina a batalha!” se o poder dele for pelo menos o dobro do poder do inimigo.

Dica do exercício 1

“Pelo menos” é >=. O dobro é poderInimigo * 2.

Solução do exercício 1

Depois do printf da diferença de poder:

if (poderTotal >= poderInimigo * 2) {
    printf("O herói domina a batalha!\n");
}

2. Mostre “Herói equilibrado!” somente se força e mana forem maiores que 10.

Dica do exercício 2

As duas condições precisam ser verdadeiras ao mesmo tempo: use &&.

Solução do exercício 2

Depois do printf da diferença de poder:

if (forca > 10 && mana > 10) {
    printf("Herói equilibrado!\n");
}
Aula 3 · A Bifurcação da Masmorra Estruturas de decisão simples, composta e aninhada
Teoria

Pré-requisitos: Módulos 1 e 2.

O if executa um bloco só quando a condição é verdadeira (decisão simples). Com else, há um caminho para o caso falso (decisão composta). else if testa outras possibilidades em sequência.

Um if dentro de outro é uma decisão aninhada: a segunda pergunta só é feita se a primeira for verdadeira.

No jogo: O jogador escolhe um caminho. No caminho 1, o resultado também depende da vida. Como o herói começa com 70 e a condição pede 80, no jogo atual ele sofre dano.

if (escolha == 1) {
    if (vida >= 80) {
        printf("Você encontra um tesouro raro!\n");
    } else {
        vida = vida - 30;
    }
} else if (escolha == 2) {
    printf("Você segue em segurança.\n");
} else {
    printf("Caminho inválido!\n");
}
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Crie o caminho 3, com uma armadilha: com mana 15 ou mais o herói passa ileso; senão, perde 10 de vida.

Dica do exercício 1

Adicione um else if antes do último else e coloque outro if dentro dele. Não esqueça de mostrar a opção no menu.

Solução do exercício 1

No menu, antes de “Sua escolha”:

printf("3 - Caminho do Meio (armadilha mágica)\n");

Antes do último else da escolha:

} else if (escolha == 3) {
    if (mana >= 15) {
        printf("Sua magia revela a armadilha!\n");
    } else {
        printf("A armadilha acerta você!\n");
        vida = vida - 10;
    }

2. Depois da escolha, avise “Vida baixa!” se a vida for menor que 50. Senão, mostre “Pronto para a batalha!”.

Dica do exercício 2

É uma decisão composta: um if com else.

Solução do exercício 2

Depois do printf da vida atual:

if (vida < 50) {
    printf("Vida baixa!\n");
} else {
    printf("Pronto para a batalha!\n");
}
Aula 4 · Combate por Turnos Estruturas de repetição
Teoria

Pré-requisitos: Módulos 1 a 3.

Um laço repete um bloco de código. O for é indicado quando sabemos quantas vezes repetir, e reúne início, condição e passo. O while repete enquanto a condição for verdadeira.

Se a condição nunca ficar falsa, o laço não termina (laço infinito). O comando break encerra o laço na hora.

No jogo: O for faz a contagem regressiva. O while mantém a batalha enquanto os dois têm vida, com um limite de turnos por segurança.

for (int contagem = 3; contagem >= 1; contagem--) {
    printf("%d\n", contagem);
}

while (vida > 0 && vidaInimigo > 0 && turno <= LIMITE_TURNOS) {
    /* ataques */
    turno = turno + 1;
}
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Faça a contagem regressiva começar em 5.

Dica do exercício 1

Só o valor inicial do for muda.

Solução do exercício 1

Troque o início do for:

for(int contagem = 5; contagem >= 1; contagem--){

2. Mostre, no fim do combate, o dano total causado pelo herói.

Dica do exercício 2

Crie uma variável com 0 antes do while e some o dano a cada turno. Se declarar dentro do laço, ela é recriada toda vez.

Solução do exercício 2

Antes do while:

int danoTotal = 0;

Dentro do while, depois de calcular o danoHeroi:

danoTotal = danoTotal + danoHeroi;

Depois do while:

printf("Dano total do herói: %d\n", danoTotal);
Aula 5 · Grimório de Habilidades Funções
Teoria

Pré-requisitos: Módulos 1 a 4.

Uma função é um bloco de código com nome, que escrevemos uma vez e usamos várias. Ela pode receber parâmetros e devolver um valor com return. Quando não devolve nada, seu tipo é void.

Ao passar um número para uma função, ela recebe uma cópia. Para alterar o valor original, devolvemos o resultado e o guardamos.

No jogo: Cálculo de dano e ataque se repetiam para herói e inimigo. Cada tarefa virou uma função. 

int calcularDano(int poder) {
    return poder / 2;
}

int atacar(char nomeAtacante[], int dano, int vidaAlvo) {
    int novaVida = vidaAlvo - dano;
    printf("%s ataca! Vida do alvo: %d\n", nomeAtacante, novaVida);
    return novaVida;
}
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Crie a função curar, que soma uma cura à vida sem passar do máximo. Use-a depois do combate.

Dica do exercício 1

Ela recebe vida, cura e vida máxima, e devolve a nova vida com return. Guarde o retorno em vida.

Solução do exercício 1

Antes do main:

int curar(int vida, int cura, int vidaMax){
    int novaVida = vida + cura;
    if (novaVida > vidaMax) {
        novaVida = vidaMax;
    }
    return novaVida;
}

No main, depois do combate:

vida = curar(vida, 20, VIDA_MAX);

2. Crie a função calcularDanoCritico e use-a no primeiro ataque do herói.

Dica do exercício 2

Receba o poder e o multiplicador. Dá para reaproveitar calcularDano dentro dela.

Solução do exercício 2

Antes do main (depois de calcularDano):

int calcularDanoCritico(int poder, float multiplicador){
    return calcularDano(poder) * multiplicador;
}

Dentro do while, depois de calcular o danoHeroi:

if (turno == 1) {
    danoHeroi = calcularDanoCritico(poderTotal, multiplicadorDano);
}
Aula 6 · Inventário e Mapa da Masmorra Vetores e matrizes
Teoria

Pré-requisitos: Módulos 1 a 5.

Um vetor guarda vários valores do mesmo tipo sob um nome. Cada posição tem um índice, que começa em 0: com 5 espaços, os índices vão de 0 a 4. O C não avisa se você passar do limite.

Uma matriz é uma grade com dois índices, linha e coluna. Para percorrê-la, usamos um for dentro de outro.

No jogo: A mochila é um vetor de itens. O mapa é uma matriz de caracteres: # é parede, . é chão e T é o tesouro.

int mochila[TAM_MOCHILA] = {POCAO, CHAVE};

for (int i = 0; i < LINHAS; i++) {
    for (int j = 0; j < COLUNAS; j++) {
        printf("%c", mapa[i][j]);
    }
    printf("\n");
}
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Conte e mostre quantos espaços vazios há na mochila.

Dica do exercício 1

Percorra o vetor com um for. Espaço vazio vale 0.

Solução do exercício 1

Depois de mostrar a mochila:

int vazios = 0;
for (int i = 0; i < TAM_MOCHILA; i++) {
    if (mochila[i] == 0) {
        vazios++;
    }
}
printf("Espaços vazios: %d\n", vazios);

2. Conte quantas paredes (#) o mapa tem.

Dica do exercício 2

Matriz pede dois for: um para as linhas e outro para as colunas.

Solução do exercício 2

Depois da declaração do mapa:

int paredes = 0;
for (int i = 0; i < LINHAS; i++) {
    for (int j = 0; j < COLUNAS; j++) {
        if (mapa[i][j] == '#') {
            paredes++;
        }
    }
}
printf("Paredes: %d\n", paredes);
Aula 7 · Ficha Completa do Herói Variáveis compostas heterogêneas (struct)
Teoria

Pré-requisitos: Módulos 1 a 6.

Uma struct cria um tipo novo que reúne campos de tipos diferentes. A declaração é o molde; cada variável criada a partir dele é uma ficha. Acessamos um campo com ponto: heroi.vida.

Ao passar uma struct para uma função, ela recebe uma cópia.

No jogo: Os dados soltos do herói e do inimigo viram uma ficha para cada personagem.

struct Personagem {
    char nome[50];
    int vida;
    int forca;
    int mana;
    float multiplicadorDano;
    int mochila[TAM_MOCHILA];
};

struct Personagem inimigo = {"Goblin", 50, 12, 8, 1.0};
Exercícios

Faça no seu rpg.c, um de cada vez, e compile com gcc -Wall.

1. Adicione o campo ouro à ficha. O herói ganha 50 ao achar o tesouro.

Dica do exercício 1

Coloque o campo no fim da struct, para não bagunçar a ordem dos valores iniciais. Acesse com heroi.ouro.

Solução do exercício 1

No fim da struct Personagem:

int ouro;

Dentro de mostrarFicha:

printf("Ouro: %d\n", p.ouro);

Depois de achar o tesouro:

heroi.ouro = 50;

2. Crie um segundo inimigo, um Orc, e mostre a ficha dele.

Dica do exercício 2

Use a mesma struct, na ordem: nome, vida, força, mana e multiplicador.

Solução do exercício 2

Depois de mostrar a ficha do Goblin:

struct Personagem orc = {"Orc", 80, 18, 2, 1.0};
mostrarFicha(orc);
