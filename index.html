Aula 1 · Criação do Personagem Variáveis, constantes, tipos, entrada, saída e expressões

Pré-requisitos: Nenhum. É o começo da jornada.

Uma variável é um espaço na memória com nome e tipo. int guarda inteiros, float guarda decimais, char guarda um caractere, e um vetor de char guarda texto. Uma constante, marcada com const, não muda depois de criada.

printf mostra informações na tela e scanf lê o que a pessoa digita. Com +, -, *, / e % fazemos contas. Entre dois inteiros, a divisão descarta a parte decimal.

No jogo: O herói precisa de nome, vida, força e mana. O %49s limita o nome a 49 caracteres, sem espaços, para não ultrapassar a memória reservada.

const int VIDA_MAX = 70;
char nome[50];
int forca, mana;

scanf("%49s", nome);
scanf("%d", &forca);
scanf("%d", &mana);

int poderTotal = forca + mana;
Aula 2 · Teste de Sorte Expressões relacionais e lógicas

Pré-requisitos: Módulo 1.

Uma expressão relacional compara dois valores e resulta em verdadeiro (1) ou falso (0). Os operadores são >, <, >=, <=, == (igual) e != (diferente). Atenção: = atribui um valor, == compara.

Os operadores lógicos juntam condições: && (e), || (ou) e ! (não).

No jogo: Um Goblin aparece. Comparamos o poder do herói com o dele para saber quem é mais forte. O jogo não sorteia números: o resultado depende dos valores digitados.

if (poderTotal > poderInimigo) {
    printf("O herói é mais forte!\n");
} else if (poderTotal < poderInimigo) {
    printf("O inimigo é mais forte!\n");
} else {
    printf("Os dois têm o mesmo poder.\n");
}
Aula 3 · A Bifurcação da Masmorra Estruturas de decisão simples, composta e aninhada

Pré-requisitos: Módulos 1 e 2.

O if executa um bloco só quando a condição é verdadeira (decisão simples). Com else, há um caminho para o caso falso (decisão composta). else if testa outras possibilidades em sequência.

Um if dentro de outro é uma decisão aninhada: a segunda pergunta só é feita se a primeira for verdadeira.

No jogo: O jogador escolhe um caminho. No caminho 1, o resultado também depende da vida. Como o herói começa com 70 e a condição pede 80, no jogo atual ele sofre dano.

if (escolha == 1) {
    if (heroi.vida >= 80) {
        printf("Você encontra um tesouro raro!\n");
    } else {
        heroi.vida = heroi.vida - 30;
    }
} else if (escolha == 2) {
    printf("Você segue em segurança.\n");
} else {
    printf("Caminho inválido!\n");
}
Aula 4 · Combate por Turnos Estruturas de repetição

Pré-requisitos: Módulos 1 a 3.

Um laço repete um bloco de código. O for é indicado quando sabemos quantas vezes repetir, e reúne início, condição e passo. O while repete enquanto a condição for verdadeira.

Se a condição nunca ficar falsa, o laço não termina (laço infinito). O comando break encerra o laço na hora.

No jogo: O for faz a contagem regressiva. O while mantém a batalha enquanto os dois têm vida, com um limite de turnos por segurança.

for (int contagem = 3; contagem >= 1; contagem--) {
    printf("%d\n", contagem);
}

while (heroi.vida > 0 && inimigo.vida > 0 && turno <= LIMITE_TURNOS) {
    /* ataques */
    turno = turno + 1;
}
Aula 5 · Grimório de Habilidades Funções

Pré-requisitos: Módulos 1 a 4.

Uma função é um bloco de código com nome, que escrevemos uma vez e usamos várias. Ela pode receber parâmetros e devolver um valor com return. Quando não devolve nada, seu tipo é void.

Ao passar um número para uma função, ela recebe uma cópia. Para alterar o valor original, devolvemos o resultado e o guardamos.

No jogo: Cálculo de dano e ataque se repetiam para herói e inimigo. Cada tarefa virou uma função.

int calcularDano(int poder) {
    return poder / 2;
}

int atacar(char nomeAtacante[], int dano, int vidaAlvo) {
    int novaVida = vidaAlvo - dano;
    printf("%s ataca! Vida do alvo: %d\n", nomeAtacante, novaVida);
    return novaVida;
}
Aula 6 · Inventário e Mapa da Masmorra Vetores e matrizes

Pré-requisitos: Módulos 1 a 5.

Um vetor guarda vários valores do mesmo tipo sob um nome. Cada posição tem um índice, que começa em 0: com 5 espaços, os índices vão de 0 a 4. O C não avisa se você passar do limite.

Uma matriz é uma grade com dois índices, linha e coluna. Para percorrê-la, usamos um for dentro de outro.

No jogo: A mochila é um vetor de itens. O mapa é uma matriz de caracteres: # é parede, . é chão e T é o tesouro.

int mochila[TAM_MOCHILA] = {POCAO, CHAVE};

for (int i = 0; i < LINHAS; i++) {
    for (int j = 0; j < COLUNAS; j++) {
        printf("%c", mapa[i][j]);
    }
    printf("\n");
}
Aula 7 · Ficha Completa do Herói Variáveis compostas heterogêneas (struct)

Pré-requisitos: Módulos 1 a 6.

Uma struct cria um tipo novo que reúne campos de tipos diferentes. A declaração é o molde; cada variável criada a partir dele é uma ficha. Acessamos um campo com ponto: heroi.vida.

Ao passar uma struct para uma função, ela recebe uma cópia.

No jogo: Os dados soltos do herói e do inimigo viram uma ficha para cada personagem.

struct Personagem {
    char nome[50];
    int vida;
    int forca;
    int mana;
    float multiplicadorDano;
    int mochila[TAM_MOCHILA];
};

struct Personagem inimigo = {"Goblin", 50, 12, 8, 1.0};
